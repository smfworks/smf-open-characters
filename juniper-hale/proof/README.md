# Proof video

`juniper-hale-proof.mp4` is a 16:9 cut of two image-to-video shots from the reference stills (A and B). Shot C was not rebuilt in this pass: the grit pass had a two-video ceiling, A and B used both, and the current 08 still must not be paired with the older C clip. Native ambient from the generations is kept; there is no score.
